・作品名：予定管理アプリ
・使用ツール：Python/Flask/SQLite/HTML・CSS/JavaScript
・概要：「こんなアプリが欲しい」という自分のアイデアをもとに、AIと対話しながら、自分のアイデアを形にしたアプリである。学生生活の時間割や予定を一つのアプリでまとめて管理できるようにすることを目的として制作した。
・主な機能：時計機能/時間割表示機能/カレンダー機能/予定管理機能/今日の運勢 
・工夫した点・努力した点：AIと対話しながらアプリを作成する中で、コードがうまく動かない原因を確認し、作りたいものを具体的に伝えるなど、質問の仕方を工夫した。また、カレンダーとSQLiteの予定を連携し、予定がある日に件数を表示したり、日付ごとの予定を表示したりする処理にも取り組んだ。JavaScriptの日付処理や予定データの取得・表示を確認しながら実装した。

・制作を通して学んだこと
個人制作では、自分の知識や技術がまだ十分でないことを実感するとともに、AIを活用しながら自分の意図したものを形にする難しさを感じた。分からない部分をそのままにせず、AIに質問したり、試行錯誤したりすることで、少しずつ完成に近づけていくことができた。一方、グループ制作では、担当箇所を分担するだけではスムーズに進むわけではなく、メンバー間で仕様や認識に少しでもずれがあると、制作全体に影響することを学んだ。これらの経験を通して、技術力だけでなく、利用する人の視点やメンバーとのコミュニケーションも意識しながら、ものづくりに取り組みたいと考えるようになった。
